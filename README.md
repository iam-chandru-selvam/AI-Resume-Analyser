# Authentication App (Firebase + React + Vite)

A full-stack authentication application built using **React**, **Vite**, and **Firebase**.  
This project demonstrates user authentication using Firebase with a modern frontend setup.

## 🚀 Features

- User Authentication (Login / Signup)
- Firebase Authentication integration
- Protected routes
- Modern React setup with Vite
- Docker support for deployment
- Firebase Functions for backend logic

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Firebase Functions
- **Auth:** Firebase Authentication
- **Hosting:** Firebase
- **Containerization:** Docker
